# Static Wireframe - Ayag Dental Clinic

Pure HTML/CSS static wireframe version of the Ayag Dental Clinic Management System.

## Pages

### Authentication
- `login.html` - Login page
- `register.html` - Registration page
- `forgot-password.html` - Forgot password page
- `verify.html` - Email verification (OTP) page

### Admin (Clinic Staff)
- `admin-dashboard.html` - Admin dashboard
- `admin-patients.html` - Patient records
- `admin-accounts.html` - Patient accounts
- `admin-appointments.html` - Walk-in appointments
- `admin-online-appointments.html` - Online appointments
- `admin-sales.html` - Sales & bookkeeping
- `admin-inventory.html` - Inventory management
- `admin-reports.html` - Reports

### Patient
- `patient-dashboard.html` - Patient dashboard
- `patient-book.html` - Book appointment
- `patient-appointments.html` - My appointments
- `patient-records.html` - Dental records

### Super Admin
- `superadmin-dashboard.html` - Super admin dashboard
- `superadmin-staff.html` - Staff management
- `superadmin-settings.html` - System settings
- `superadmin-reports.html` - Reports & analytics

## How to Use
Open any `.html` file directly in a browser. All pages are interlinked via sidebar navigation.
